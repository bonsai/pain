# Pain と Issue の違い

## 一言で

> Pain は「何が苦しい／望ましくないか」
>
> Issue は「何を解決する仕事として扱うか」

## 関係

Pain
  ↓
Concern
  ↓
Observation
  ↓
Pain candidate
  ↓
Confirmation
  ↓
Issue
  ↓
Action
  ↓
Result
  ↓
Evaluation

PainはWorld側の状態・経験に属する。

Issueは、そのPainに対して主体が「扱う」と決めた作業単位である。

## 比較

| | Pain | Issue |
|---|---|---|
| 主語 | 痛みを経験する主体 | 解決に取り組む主体 |
| 対象 | 問題的な状態・経験 | 解決すべき仕事 |
| 時間 | 過去・現在から発見できる | これからの行動に向く |
| 解決策 | 原則として含めない | Actionを含み得る |
| 証拠 | Experience / Observation | Progress / Result |
| 状態 | acknowledged / suspected 等 | open / in_progress / closed 等 |
| 目的 | Painを正しく捉える | 変更を起こす |

## 重要な非対称性

1つのPainから複数のIssueが生まれることがある。

Pain「毎回イベント情報を探すのが大変」
  ├── Issue: データ収集を自動化する
  ├── Issue: 検索UIを作る
  └── Issue: 情報源を整理する

逆に、1つのIssueが複数のPainを扱うこともある。

したがって Pain : Issue = 多対多 として扱える。

## IssueにしないPain

まだ以下が不明なら、すぐIssue化しない。

- 本当に誰のPainなのか
- 何が起きているのか
- 再現するのか
- 何を変えたいのか
- 本人がPainとして認識しているか

この段階ではPain Discoveryを続ける。
